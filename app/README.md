# ふりかえり伴走

「振り返りがめんどくさい」人のための、毎日の振り返りに伴走するアプリです。
1日1回、ひとタップから始められるステップ式のフローで、ジャーナル・スキルの手応え・目標の達成度・次の一歩をまとめて記録できます。

## 主な機能

- **今日**: 気分 → できたこと → つまずき → 良かったこと → （登録済みなら）スキルの手応え → 目標の達成度 → 明日の一歩、という軽いステップ形式の振り返りフロー。どのステップも空欄のままスキップ可能。
- **記録**: 連続振り返り日数（ストリーク）、ネクストアクションの一覧とチェック、過去の振り返り履歴。
- **目標**: 目標の追加とスライダーでの達成度（0-100%）管理、達成した目標のアーカイブ。
- **スキル**: 伸ばしたいスキルの登録と、振り返りのたびに記録される1-5の手応え・推移。
- **設定**: PWAとしてホーム画面に追加してアプリのように起動、毎日決まった時刻に「そろそろ振り返りの時間です」というPush通知を受け取れます（通知には `../server` の起動が必要）。

## データの保存

ジャーナル・目標・スキルなどの記録はサーバーを使わず、ブラウザの `localStorage` にすべて保存されます（キー: `reflect-app:v1`）。
Push通知の購読情報だけは `../server` 側に保存されます（詳細はそちらのREADME参照）。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド
npm run lint      # oxlint
```

### 通知(Push)を有効にする場合

1. `../server` をセットアップして起動する(READMEを参照)
2. `.env.example` を `.env` にコピーし、`VITE_API_BASE_URL`(サーバーのURL)と `VITE_VAPID_PUBLIC_KEY`(サーバーと同じ公開鍵)を設定してビルドし直す
3. アプリの「設定」タブから通知をオンにする

**iPhoneの場合**: iOS 16.4以降で、かつ **ホーム画面に追加してアプリとして開いた場合のみ** 通知を受け取れます。Safariのタブのままでは動作しません。
