# ふりかえり伴走

「振り返りがめんどくさい」人のための、毎日の振り返りに伴走するアプリです。
1日1回、ひとタップから始められるステップ式のフローで、ジャーナル・スキルの手応え・目標の達成度・次の一歩をまとめて記録できます。

## 主な機能

- **今日**: 気分 → できたこと → つまずき → 良かったこと → （登録済みなら）スキルの手応え → 目標の達成度 → 明日の一歩、という軽いステップ形式の振り返りフロー。どのステップも空欄のままスキップ可能。
- **記録**: 連続振り返り日数（ストリーク）、ネクストアクションの一覧とチェック、過去の振り返り履歴。
- **目標**: 目標の追加とスライダーでの達成度（0-100%）管理、達成した目標のアーカイブ。
- **スキル**: 伸ばしたいスキルの登録と、振り返りのたびに記録される1-5の手応え・推移。

## データの保存

サーバーは使わず、ブラウザの `localStorage` にすべて保存されます（キー: `reflect-app:v1`）。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド
npm run lint      # oxlint
```
